# 现行口径全文（Guard 规则库）

> 本文是 `SKILL.md` 的详细版。所有「现行」规则以此为准；历史作废口径只在 `POSTMORTEM.md` 里作为教训保留。

## 1. 四元组与表型

**战区 × 渠道 × 月份 × 版本**，任一不同 = 另一张表。不套列位 / 口径 / 源表 / 基线；**价格表绝不串月**。

| 表型 | 主表 | 表头行 | 型号列 | 明细 sheet |
|---|---|---|---|---|
| A 长沙·五星 | `制表` | 2 | F 商品名称 | `原始数据` |
| B 长沙·苏宁 | `苏宁制表` | 1 | C 商品_名称 | `销售明细` |
| C 南宁·苏宁 | `制表（X月）` | 3 | D 名称 | `X月费用明细核对表` |
| D 广西·五星 | `制表 （X月）` | 3 | D 商品名称 | `X月费用明细核对` |

- 行数逐月变，**绝不写死**；动手前用 `identify_table.py` 交叉校验「文件名月份 vs 数据日期月份」。
- 识别器报冲突（文件名说 10 月、数据主要是 9 月）→ **立即停下问人**。
- 型 B 若业务已预插五步列，走「审核版基座」：只刷值不插列。

## 2. 源表：唯一真值源

外部价格表目录（按 `config/profile.json` 的 `price_root` + `source_paths` 登记）：

```
<price_root>/<N月>/智屏/大区/华南大区N月智屏价格表*.xlsx
<price_root>/<N月>/智屏/总部/TCL智屏26年N月线下主价格表*.xlsx
```

🔴 **绝不用业务 workbook 内嵌的价格表 sheet 作为真值源**（型号不全、滞后、缺列）。
按 sheet 名取，不按索引（sheet 顺序每月不同）：

| 源表 | sheet | 型号 | 取值 |
|---|---|---|---|
| 大区表 | `连锁+区域连锁价格表` | F 型号（表头 r1） | G 连锁供价、K 当月零售价（子标题在 r2，数据 r3 起） |
| 总部表 | `线下渠道` | D 型号（表头 r4/r5） | **G 最低零售价**（取 G 不取 F，F 空值率高） |
| 淘汰机价格表 | 同名 sheet | C 型号 | D 现净供价 |

- 大区表是**双层表头**：找「型号」扫 r1，找「连锁供价/当月零售价」扫 r2。
- 总部表文件名后缀每月不同（有 `(1)` / `(2)` / 无后缀），**按实际登记，不凭记忆拼**。
- 新月份价格表到手：先登记到 profile，实测核验结构，再干活。

## 3. 三列独立匹配优先级（三列互不串价，顺序不许跳）

> 🔴 业务负责人 11:32 再次强调、12:17 裁决「**OA 优先**」后的现行口径。

```
① 供价 I（大区供价）
   大区价格表「连锁供价」 → 匹配不到才匹配 OA 供价
   🚫 绝不拿总部表 F「连锁供价」或淘汰机表 D「现净供价」核供价（那是总部口径，混进来就乱）

② 公司底价 S（大区零售价）
   大区价格表「当月/最低零售价」 → 匹配不到 → **OA 到手价优先** → 再战区表最低零售价

③ 总部价 AD（总部最低零售限价）
   总部表「线下渠道」G 最低零售价 → 匹配不到 → **OA 到手价优先** → 战区表 → 淘汰机现净供价
```

🔴 **第五步列的归属（用户 11-12 14:44 纠正，最容易说反）**：
- **AD「总部最低零售限价」是【核对方】自己要填的列，不是业务填的**——业务不掌握总部价，
  也没法填。业务原表里同名的那一列只是空壳：358 行 `=O{r}`（直接引用「公司授权底价」）、
  354 行空白、10 行外链 XLOOKUP，**没有一行是真正的总部价**。
- 核对动作 = 先按上面的来源链把 **AD 逐行刷成常数**（808 行全有值，零公式、零空白），
  **AD 填完之后，再在紧邻其右的 AE「备注」列写取数依据 / OA 证据 / 短标注**。
- 所以顺序是 **AD → AE**，两列都是核对方产出；AE 绝不先于 AD，也不许把 AD 说成「业务列／业务填的」。
- 硬断言见 `check_ad_ae_ownership.py`（8 项，已挂门禁 G5）：AD 全常数零公式 / 不照抄公司授权底价 /
  不盲从业务「核对」外链 / AE 紧邻右侧且为备注文本 / 先 AD 后 AE / AD 无空白。

- 🔴 **OA 优先的实质**：有 OA 的型号（如带 `-A` 的包销机）**严格型号**在外部价格表匹配不到时，
  走 OA 价，**不许靠去 `-A` 后缀硬凑大区/总部表价**；无 OA 的型号才允许分级去后缀找同机型。
  否则会把含税含券口径差重新算成几百条差异、推翻金额链与处罚结论。
- 🔴 **governing OA 唯一真值源 = 依据列（AB）的 OA 号**，不是纯销售日期推断；日期只作窗口校验。
  实例：某两天的退货红冲行 AB 写的是前一张 OA（到手价较高），按日期会误推到后一张 OA（到手价较低）。
- 三列各自独立：供价只认大区/OA 供价、底价认大区/OA/战区零售价、总部价认总部/OA/战区/淘汰机；
  **一列一个来源链，绝不互相借价**。
- 内嵌的「总部价格表」「制表 (2)」「OA备案」「KA+保点客户」均为历史遗留，不作真值源。
- 四路兜底仍保留：外部大区 / 总部线下 / 淘汰机 → 仍无 → 内嵌「战区X月价格表」(D型号 / H最低零售价 / I结算价)
  与「N月OA截图」各张 OA → 仍无才写「请业务提供OA依据」。
- 已匹配的值不覆盖；同型号多行按标准行 / 等级机行分开处理。
- 匹配不到先查商品名判定品类：若「原始数据」里是智能门锁等非智屏品类，智屏价格表不适用，**不是无效待办**。
- 等级机：带 `(特一)/(特二)/(特三)` 是不同政策档位价，**只有等级机价不得硬凑标准价填 AD**。
- 每版做**全量逐行回归**（全部数据行 × I/S/AD 独立重算），不能只改被点名的几行。

## 5. 表头批注 = 口径真值源

- 判差异前**先读 r1 批注**：例如「含税含券」「有OA按渠道供价−我司分摊费用 / 无OA按战区表最低零售限价 / 一票机=渠道供价」。
- 含税含券价与 OA 净价之间的固定差额是**口径传导，不是价格差异**；曾据此凭空造出 444 条差异，已撤销。
- 不同口径的数**禁止直接相减**。

## 6. 三个价格 = 三列 = 三个专属词

| 列 | 核对对象 | 差额 | 唯一「不对」描述 | 白名单 |
|---|---|---|---|---|
| K(11) | 供价核对 H vs I | J | `供价不对` | 一致 / 退货 / OA备案价 |
| U(21) | 公司授权底价核对 R vs S | T | `授权底价不对` | 同上 |
| AE(31) | 总部价格核对 AD | — | `总部价格不对` | OA 证据行保留原文 |

- 「一律写供价不对」**已作废**；「U 写底价不对」也统一为「授权底价不对」。
- AE 列 OA 证据行（含 OA 号、审批人、批准日期）是证据备注，**保留不动**。
- 情况表类型名仍叫「总部底价核对」、F 列仍写具体对账价 —— 未点名不动。

## 7. 业务视图脱敏

- K/U/AE **只留待办标注**：价格表出处、行号、取数细节、「AD取此价」、「请业务确认或提供OA依据」等一律不进表。
- 核对情况表**结论说明区**（如 `r104` 起若干行，A:H 合并区）从表内 `ClearContents` 清空，不删行；内容**只在对话里单独发负责人**，不落文件、不给业务。
- 情况表条目正文、G/H 业务填写列、OA 证据行保留。
- 「核对结果：」这类内部结论，业务打开表就能看到 → 必须移出。

## 8. 零基准保护

- 差额列用真公式 `=IF(S=0,0,R-S)`（供价侧同理），未匹配基准填 0 时返 0，避免把全额供价算成超授权。
- `I=0 且 S=0` 的行：J=H、T=0，标「不对」但差额 0 **不是假差异**。
- 校验第 7 项按 `I!=0 / S!=0` 豁免，第 8 项保证这些行**不标「一致」**。
- 🔴 曾想「所有 T=0 行都豁免」让校验变绿 —— 已否决。**先坐实事实再改判据**。

## 10. 核对情况表与回填

- 位置：紧邻主表之后，标签染红；8 列，末两列黄底供业务填写；标准样式用 `style_check_sheet.apply_standard(cs)`。
- 只列**正向**，退货红冲不列；说明价 = H / R / AD。
- 任何 sheet **不能删行 / 改序号 / 改结论**；需增删行才整表重建（读条目 → Delete → Add → 单参数 `Move(Before=...)` → 回填 → 套样式）。
- 业务填完 G/H 后回填：供价核对→K、公司授权底价→U、总部底价→AE，追加 `｜业务反馈：{原因}；依据：{依据}`，不覆盖原标注、幂等、另存新版本、落盘自动复跑一致性。
- G/H 全空时**不硬改文件、不编原因**。

## 11. OA 与证据

- 匹配不到 → 业务提供/OA → 重匹 → 仍无 → 业务自填。
- 证据备注写**来源 + OA 最终审批人 + 批准日期**。
- AB 填死（OA报备价 / 统一供价 / 包销机）= 非差异不列；「N月销指」是常规标记不是填死；「不一致需人工核实」= 待办必须列。
- OA 按「销售日期 + AB 的 OA 号」**分段生效**，禁整月一刀切；OA 是独立文件，别当成另一份的续办。
- 总部 G **严格型号**查得到时 AD 取 G，不用 OA 零售价覆盖；严格型号查不到（如带 `-A` 包销机）则按「OA 优先」取 OA 到手价，不去后缀硬凑表价。

## 12. 交付命名与版本

```
原名—<负责人>M-D核对VN.xlsx      em dash U+2014，无括号，M/D 不补零
```

- `VN` = **当天第 N 版，从 V1 起算**；🔴 **跨日一律重新从 V1 开始，绝不沿用前一天版本链**。
- 当天内误编号 → 按当天顺序重编号；旧版不追溯改名。
- 存业务往来目录对应月份下，**不放桌面**。
- `--next` 自动取当天下一版名；`--prev` 用上一版做全簿 diff。

## 13. 金额链与处罚口径

- 链路：`AD → AG(33) → AH(34) → 汇总表 K/L/C27/C28`；`C26` 为孰低值。
- 改 AD 必须**逐格重写相关原 Formula** 触发重算，公式文本零改动；禁 `CalculateFullRebuild()`。
- 处罚取 `min(C26, C28)`，`|值| > 1%` 即罚；正文不列总部版数字。
- B券/退货与「促销费发生额」按恒等式 `X+Y=Q+P` 先验，别拿 Q 单项比 X（必出假异常）。
